Kisan Mitra – Detailed Project Description

Kisan Mitra is a smart agriculture web application designed to provide farmers with a centralized digital platform for managing crops, monitoring farm conditions, understanding agricultural markets, and accessing farming guidance. The system is designed with a modern, responsive interface so that important farming information can be accessed easily from a desktop, laptop, tablet, or mobile device.

The main objective of Kisan Mitra is to simplify agricultural decision-making by bringing multiple farming-related functions into one application. Instead of navigating through different platforms for crop information, market prices, weather conditions, and agricultural advice, the user can access these features through a single dashboard.

The application begins with a Dashboard that provides a quick overview of the farmer's farm. It displays important information such as current temperature, rainfall, crop count, wheat market price, market signals, and daily agricultural recommendations. Interactive cards and navigation elements allow the user to move directly to the relevant sections of the application.

The My Crops module is designed for crop management. It provides individual information for crops such as wheat, onion, and tomato, including crop variety, cultivated area, growth stage, soil condition, and crop health percentage. Each crop can be selected to view additional information through an interactive details window. This allows farmers to monitor the development and general condition of their crops in an organized manner.

The Market module focuses on agricultural market intelligence. Users can select different crops and view their corresponding mandi prices, price changes, estimated target prices, and market trends. The application also provides mandi-wise comparisons, helping users understand how prices differ between locations such as Lasalgaon, Pune, and Nashik. A visual seven-day price trend is included to make market movement easier to understand.

The AI Advisory module acts as an interactive agricultural assistant. Farmers can enter questions related to irrigation, crop conditions, market prices, and farming practices. The system provides relevant predefined advisory responses and also includes quick-question options for common farming queries. Along with the chat interface, the module provides a farm-health overview and daily farming tips.

Kisan Mitra is developed using React and Vite, with CSS used for the user interface and Lucide React used for interface icons. React state management is used to handle navigation, crop selection, market filters, interactive crop details, and the AI advisory conversation. The application is designed to operate without dependency on external APIs, making it lightweight and straightforward to demonstrate and deploy.

The application follows a modular structure in which each major agricultural function is represented as a separate section while maintaining a consistent visual design throughout the system. Its responsive layout also ensures that the interface adapts to different screen sizes.

Overall, Kisan Mitra demonstrates how modern web technologies can be used to create a practical digital agriculture platform that combines crop management, market intelligence, weather information, farm monitoring, and agricultural advisory services into one unified system. The project can be further enhanced in the future by integrating real-time weather APIs, live mandi data, user authentication, cloud databases, multilingual support, notifications, and advanced AI-based recommendations.
